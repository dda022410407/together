# Architecture Decision Records (ADR)

## 2. C++ 및 Python 하이브리드 아키텍처 도입
* **날짜:** 2026-07-15
* **상태:** 채택됨 (Accepted)
* **배경 (Context):** 
  오답 분석을 위한 AI 패턴 분류 웹앱을 개발함에 있어, 팀원(친구들)은 AI 모델링(Python)에 집중하고, 개발 리드(질문자)는 저수준(Low-level) 언어인 C++에 익숙한 상황입니다. 또한 프론트엔드는 AI 어시스턴트를 활용하여 고속으로 개발하고자 합니다.
* **결정 (Decision):** 
  - **메인 백엔드:** C++ (`cpp-httplib` 사용)로 초고성능 API 서버를 구축합니다.
  - **AI 백엔드:** Python (FastAPI) 기반으로 마이크로서비스를 구축하여 메인 서버와 통신합니다.
  - **프론트엔드:** React를 사용하여 AI 주도(AI-driven)로 개발합니다.
* **결과 (Consequences):** 
  - 서로 편한 언어로 독립적인 개발(MSA)이 가능합니다.
  - 추후 대규모 연산이 필요할 경우 C++ 백엔드에 CUDA를 쉽게 통합할 수 있습니다.
