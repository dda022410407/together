# Architecture Decision Records (ADR)

## 3. 프론트엔드 담당자 변경 및 Next.js 도입
* **날짜:** 2026-07-15
* **상태:** 채택됨 (Accepted)
* **배경 (Context):** 
  프론트엔드(웹 UI) 개발 및 회원 관리 로직 작성을 위해 프레임워크 선정이 필요했습니다. AI 어시스턴트가 전담하려 했으나, 팀원(친구1)이 직접 프론트엔드를 담당하기로 결정되었습니다.
* **결정 (Decision):** 
  - **프론트엔드 프레임워크:** Next.js (회원 관리, 라우팅, API 연동의 편의성)
  - **역할 분담 최종:**
    - `친구1`: Next.js 프론트엔드 (화면 및 회원 관리)
    - `친구들(기타)`: Python AI 서버
    - `질문자`: C++ 코어 백엔드 API
* **결과 (Consequences):** 
  - 각자의 역할이 명확해졌으며, Next.js 보일러플레이트를 세팅하여 친구1이 바로 작업할 수 있도록 지원합니다.
